# KitchenX prototype logins

Open `kitchenx-v2.html`, choose **Login**, then pick **Customer** or **Admin**.

## Customer

Any username and password on the Customer tab opens the end-customer app (`customer.html`).

## Admin

Use the Admin tab with one of these accounts. Each one opens a separate dashboard.

| Role | Username | Password | Opens |
|---|---|---|---|
| Platform Admin | `Admin` | `Admin@123` | `admin.html` — full platform console |
| Finance Admin | `FinanceAdmin` | `FinanceAdmin@123` | `finance.html` |
| Technical Admin | `TechnicalAdmin` | `TechnicalAdmin@123` | `technical.html` |
| Relationship Manager | `RM` or `RelationshipManager` | `RM@123` or `RelationshipManager@123` | `rm.html` |
| Warehouse Supervisor | `Supervisor` | `Supervisor@123` | `warehouse.html` — floor only |
| Warehouse Manager | `Manager` | `Manager@123` | `warehouse.html` — floor plus approvals, racks, expiry, routing |

Username match is case-insensitive. Password must match exactly.
